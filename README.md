# My System — расширение для Owlbear Rodeo

Лист персонажа D&D 5e (броня — Challenge Mode, The Dungeon Coach) и общий лог бросков.

**Ссылка для установки в Owlbear:** `https://dyimko.github.io/owlbear-module/manifest.json`
(Профиль → Add Extension → вставить ссылку → включить в комнате)

## Как пользоваться
- Кнопка расширения слева вверху — список токенов на сцене (клик открывает лист), кубики и лог бросков.
- Или выделить токен → в контекстном меню значок «Лист персонажа».
- Данные листа хранятся на самом токене и видны всем игрокам.

## Как обновить сайт
1. Изменения в папке проекта.
2. GitHub Desktop → Summary (любой текст) → **Commit to main** → **Push origin**.
3. Через ~1 минуту GitHub Actions пересоберёт сайт (вкладка Actions на GitHub).

## Структура
| Файл | Что делает |
|---|---|
| `public/manifest.json` | Название, иконка, popover, фоновый скрипт |
| `src/main.ts` | Панель расширения: токены, кубики, лог |
| `src/background.ts` | Контекстное меню токена и всплывашки бросков |
| `src/sheet.ts` | Лист персонажа |
| `src/types.ts` | Модель данных и правила 5e, справочник брони |
| `src/tips.ts` | Тексты подсказок при наведении |
